# Internationalization

Cadence ships English and Spanish and can switch language at runtime without
restarting the app. The Go backend stays language-neutral: it emits stable error
codes and raw diagnostic detail, while the frontend owns all user-facing copy.

## Catalog layout

| File | Role |
|---|---|
| `frontend/src/shared/i18n/locales/en.ts` | Typed source catalog. `as const`; `MessageKey = keyof typeof en`. |
| `frontend/src/shared/i18n/locales/es.ts` | Spanish catalog typed as `Record<MessageKey, string>`. Missing or unknown keys are a TypeScript error. |
| `frontend/src/shared/i18n/i18n.svelte.ts` | Locale runtime, ICU formatter cache and cross-window storage sync. |
| `frontend/src/shared/i18n/index.ts` | Public barrel: `t`, `i18n`, `initI18n`, `LOCALE_STORAGE_KEY`, `LOCALES` and types. |
| `frontend/scripts/check-i18n.mjs` | AST guard that fails on untranslated literals. |

Both catalogs are bundled as TypeScript modules. English is the eager base
catalog; Spanish is a separate lazy chunk (`es-*.js`), so the compact window
does not download it until the user selects it.

## Key groups

Keys are flat strings grouped by prefix so a component's copy is easy to find:

| Prefix | Scope |
|---|---|
| `ui.*` | Shared primitives (`Close`, `Cancel`, `Retry`, plural items). |
| `queue.*` | Queue panel labels, provider notes and empty/loading states. |
| `browse.*` | Browse shell, navigation, search, library, entity pages, pairing gates and settings. |
| `app.*` | Compact shell labels (player region, popover backdrop, dismiss). |
| `player.*` | Compact player status, shuffle tag, visualizer control and fallbacks. |
| `transport.*` | Play/pause, previous/next, shuffle and repeat labels and shortcuts. |
| `progress.*` | Playback position label and `"{position} of {duration}"`. |
| `volume.*` | Volume slider, mute/unmute and percentage text. |
| `device.*` | Device picker, device metadata, active/restricted states and local playback. |
| `titlebar.*` | Window titlebar, queue toggle and window controls. |
| `visualizer.*` | Compact visualizer mode labels. Theme names remain proper nouns. |
| `skin.*` | Declarative skin runtime fallbacks. |
| `albumArt.*` | Album art accessible label. |
| `errors.*` | Known player and engine error codes plus generic fallbacks. |
| `music.*` | Engine/pairing store notices. |
| `skins.*` | Skin management notices and safe-mode errors. |

Brand/product names (`CADENCE`, `Cadence`, `Clarity`, `Spotify`, `Premium`,
`JAM`) stay as proper nouns in both catalogs and in the guard allowlist.

## Translating in components

Use `t(key, params?)` from `shared/i18n` inside scripts and templates. Reading
the reactive `i18n.locale` through `t()` makes Svelte templates re-render when
the locale changes.

```svelte
<script lang="ts">
  import { t } from "../../shared/i18n";
</script>

<h1>{t("browse.libraryTitle")}</h1>
<span>{t("progress.value", { position: "0:30", duration: "3:00" })}</span>
```

Rules:

- Never concatenate translated fragments when word order can change. Put the
  whole sentence in one ICU message with named parameters.
- Use ICU plurals and selects for counts and variants, for example
  `"{count, plural, one {# item} other {# items}}"`.
- Interpolate numbers with ICU parameters rather than building strings in
  JavaScript.
- Keep `title`, `aria-label`, `placeholder` and `alt` translated; the guard also
  checks visible text nodes.
- Data from Spotify (track titles, artist names, device names, skin names) is
  not translated.

## Locale lifecycle

- `initI18n()` runs once per webview before either surface mounts. It installs
  the cross-window listener, reads `localStorage["cadence.locale"]`, falls back
  to `navigator.language` (`es*` → `es`, otherwise `en`), and applies the
  catalog with `setLocale`.
- `setLocale(locale)` loads the catalog, clears the ICU formatter cache, updates
  `i18n.locale` and `document.documentElement.lang`, and persists the choice.
  Slow loader responses are latest-wins.
- `syncLocale(locale)` applies a catalog received from another window but does
  not persist it. `startStorageSync()` listens for `storage` events on
  `cadence.locale`; storage events do not fire in the writing window, and
  `syncLocale` never writes back, so there is no feedback loop.
- The Browse **Settings → Appearance → Language** selector calls `setLocale`.
  The compact window has no language selector; its settings button opens Browse
  Settings. Changing the language in either window updates the other on the next
  storage event.

## Translation guard

Run:

```sh
cd frontend
npm run i18n:check
```

`frontend/scripts/check-i18n.mjs` parses every `frontend/src/**/*.svelte` with
the Svelte compiler and walks template nodes only (scripts and styles are
skipped). It reports:

- literal text nodes with non-whitespace content;
- literal `title`, `aria-label`, `placeholder` and `alt` attribute values.

Expressions such as `{t("ui.close")}` pass. The allowlist covers brand names,
numbers, units (`kbps`, `kHz`, `Hz`, `GB`, `MB`, `ms`, `min`, `s`) and separator
symbols (`%`, `·`, `—`, `–`, `×`, `↗`, `▶`, `◀`, `→`, `←`, `•`, `+`, `-`).
There is no `--fix` mode. A clean run prints nothing and exits 0; any finding
prints `file:line: message` and exits 1.

The check runs in `build/Taskfile.yml` (`check:frontend`, `lint:frontend`) and
in the CI frontend step, so a new literal fails the build.

## Backend error policy

The backend is not localized. Stable codes plus raw diagnostic detail cross the
API boundary; the frontend chooses the catalog copy.

### Engine state

`engine.AudioState` carries:

- `ErrorCode` — a stable code for known local-engine states:
  `engine_not_installed`, `engine_config_error`, `engine_start_failed`,
  `engine_not_ready`, `engine_stopped`, `engine_disabled`,
  `engine_not_running`.
- `Error` — the unchanged English diagnostic string. It is shown as a
  collapsible technical detail, never as the only message.

The catalog clears both fields when the engine is healthy. Unknown codes and
missing codes fall back to `errors.engineUnknown` in the Browse engine gate.
Demo mode returns `engine_disabled`.

### Player state

`playback.PlayerError` carries `Code`, `Message`, `Retryable` and
`RetryAfterSeconds`. The frontend maps the known codes
(`not_authenticated`, `audio_unavailable`, `no_active_device`) through
`frontend/src/lib/player-error.ts` to `errors.*` keys. Unknown codes show a
generic `errors.playback` headline while `Message` stays in the element's
`title` as a diagnostic detail.

### Skin validation

Skin validation warnings and `SkinCatalog.LastError` are raw English diagnostic
detail from Go. The known safe-mode failure is mapped through
`skins.errorSafeMode`; other skin errors remain raw so the exact parser or
filesystem failure is not lost. This is a known limitation until skin warnings
gain structured codes.

## Adding or changing copy

1. Add the key to `en.ts` with the English copy that should remain the source of
   truth.
2. Add the same key to `es.ts` with neutral Spanish. TypeScript enforces parity.
3. Replace the literal in the `.svelte` file or store with `t(key, params)`.
4. If the string comes from Go, add a stable code at the source and map it in
   the frontend; keep the raw message as detail.
5. Run `npm run i18n:check`, `npm run check` and `npm run test`.

Tests assert that both catalogs have the same keys, that no value is empty and
that every message parses as ICU. A component test switches the locale to
Spanish, renders `Transport`, asserts Spanish labels and restores English.

## Verification and known limitations

- Unit gates: `npm run i18n:check`, `npm run check`, `npm run lint`,
  `npm run format`, `npm run test`.
- Full gates: `task verify`, `task build`.
- Live GTK/language-switch smoke is pending user verification: switch to
  Español in Browse Settings and confirm the compact window updates.
- Raw Go skin-validation warnings remain English diagnostic detail.
